# GitHub User Lookup

A simple web app that looks up any public GitHub user's profile using the GitHub REST API, built with vanilla HTML, CSS, and JavaScript.

## Features

- Search any GitHub username
- Displays avatar, name, bio, public repo count, followers, and following count
- Links directly to the user's real GitHub profile
- Handles invalid usernames gracefully with a proper 404 error message

## Technologies Used

- HTML5
- CSS3 (Flexbox, responsive layout)
- Vanilla JavaScript (async/await, fetch API, template literals, dynamic DOM rendering)
- GitHub REST API (public, no authentication required)

## How to Run

This is a static site with no build process. Serve the folder locally with: npx serve

Then open the printed local URL in your browser.

## Project Context

This is Project 2 of a structured MERN full-stack development course, focused on consuming a real third-party API and rendering the response dynamically, using async/await and proper error handling.
